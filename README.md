DecoBot v2.0 — Rule-Based AI Chatbot
A deterministic rule-based chatbot built in Python using dictionary-based O(1) intent lookup, input sanitization, sentiment analysis, and conversation memory.
Features:
O(1) dictionary intent matching (30+ intents)
Input sanitization — lowercasing, punctuation removal, abbreviation expansion
Confidence-scored intent matching (3 levels)
Sentiment analysis (positive / negative / neutral)
Conversation memory, session history & stats
Built With
Python 3 — re, random, collections, datetime
Part Of
DecodeLabs Industrial AI Training Kit — Batch 2026
